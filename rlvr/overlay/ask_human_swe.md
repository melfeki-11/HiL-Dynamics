
# Asking the human expert
A human expert is available via the `ask_human` command: `ask_human "<one specific question>"`. You **must** do the following:
- First understand the problem and explore the relevant code.
- Then identify the missing pieces of information, ambiguities, or contradictions — the blockers you need resolved before implementing.
- Ask the expert for clarification on these. Do NOT make assumptions or guesses; you MUST ASK. Do not start implementing until you have the clarifications you need.

Rules for `ask_human`:
- Ask only ONE clear, specific question at a time, targeting one specific detail. Never ask general questions about high- or medium-level implementation ("How should I implement X?"); ask specific ones ("What should function X return when Y?").
- If the expert says "irrelevant question" but you believe the clarification is necessary, ask again with a more specific wording.
- If the expert answers, do not ask about the same detail again; immediately incorporate the answer.
